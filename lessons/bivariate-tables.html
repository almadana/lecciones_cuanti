Tablas Bivariadas 3/5

Relación entre nivel educativo y satisfacción con la vida

Las tablas bivariadas te permiten explorar la relación entre dos variables categóricas. En esta lección aprenderás a interpretar frecuencias absolutas, porcentajes por fila y columna, y cómo visualizar estas relaciones con gráficos de barras apiladas.

💡 Cosas que puedes probar:

  • Observa las frecuencias absolutas en la primera tabla
  • Cambia entre porcentajes por fila y por columna
  • Compara las distribuciones entre diferentes niveles educativos
  • Analiza el gráfico de barras apiladas para visualizar las relaciones
  • Interpreta los porcentajes para entender las diferencias entre grupos
  • Observa cómo los colores representan las diferentes categorías

Interpretación

  • La tabla muestra la relación entre el nivel educativo y la satisfacción con la vida
  • Se presentan dos tablas:
    • Frecuencias absolutas: número de casos en cada combinación
    • Frecuencias porcentuales: distribución relativa que puede verse por filas o columnas
  • El gráfico de barras apiladas permite comparar las distribuciones porcentuales:
    • Por filas: muestra cómo se distribuye la satisfacción dentro de cada nivel educativo
    • Por columnas: muestra cómo se distribuye el nivel educativo dentro de cada nivel de satisfacción
  • Los totales marginales ayudan a entender la distribución general de cada variable

Resumen de Conceptos Clave

Tablas Bivariadas:

  • Tabla de contingencia: Organiza datos de dos variables categóricas
  • Frecuencias absolutas: Número de casos en cada combinación
  • Frecuencias porcentuales: Distribución relativa por filas o columnas
  • Totales marginales: Suma de filas y columnas

Interpretación:

  • Las tablas bivariadas revelan patrones de asociación
  • Los porcentajes por filas muestran distribución condicional
  • Los porcentajes por columnas permiten comparar grupos
  • Los gráficos apilados visualizan las distribuciones

Fórmulas Importantes:

Porcentaje por filas:
% = (fij / fi.) × 100
Porcentaje por columnas:
% = (fij / f.j) × 100
Porcentaje del total:
% = (fij / N) × 100
